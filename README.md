## 📂 Other Projects

*Built from real datasets, with measurable results.*

| Project | What it does | Links |
|---|---|---|
| **CreditWise: Loan Approval Prediction** | scikit-learn pipeline (imputation, scaling, one-hot encoding) on 950 applicant records with 18 features and 31% approvals. A class-balanced Random Forest reached **0.91 F1 and 0.98 ROC-AUC** on a stratified 20% test set, versus 0.81 F1 for a logistic-regression baseline. Credit score and DTI ratio were the strongest predictors. Deployed as a Streamlit app with live predictions, confidence scores and feature importance. | [Source](https://github.com/ShivamChavan2311/CreditWise) |
